# Mode flows, currencies and account progression

Run `sql/20261104-progression-pve.sql` after `sql/20261104-online-runtime.sql` in Supabase SQL Editor. It is rerunnable. Existing accounts/rooms are preserved. New accounts acquire their wallet automatically on first progression read. Keep the service-role key server-side.

- Select Mode has one Start action. Rank opens the rank overview first; its Find Match button joins the durable online queue. LMS opens its own room browser. Ordinary Create Room creates casual classic PvP only; cooperative PvE is labeled as future work.
- PvE Tower is server-owned, persists stage and combat, and resumes from the latest run. Each new stage restores the player's HP and starts fresh combat. The bot loadout progresses through available weapons: Greatsword, Bow, Rock, Revolver, Dagger, Chronos, Leaf, Infinity. There is no Uncommon weapon in the current catalog; no fictitious Uncommon tier is shown. After Infinity, loadout stays Secret and bot HP keeps rising by 15 per stage.
- Gem/EXP PvE reward for stage n (capped to 100 for reward size): floor(12+6*n^1.3) Gem; floor(20+12*n^1.4) EXP. Ruby starts at stage 5 (1); stage 8+ grants 2. The event key uses the actual stage, so later Secret stages still reward wins. Losses give no PvE currency.
- Ranked win: 100 Gem, 5 Ruby, 250 EXP; loss: 30 Gem, 1 Ruby, 80 EXP. LMS win: 60/2/150; loss: 15/0/50. Settlement is once per battle, in the same transaction as rank updates.
- Wallets and rewards use private server-only tables. PvE outcomes are generated by the server; clients submit actions, not reward amounts or winning states. CAS rejects stale PvE requests. Reward ledger prevents replayed payouts.
- Level starts at 1. To advance from level L requires 100*L² EXP. Level cap is 100; about 32.8 million total EXP is needed, with earned EXP retained.
- Rank order: Đồng → Sắt → Vàng → Kim Cương → Bạch Kim → Huyền Thoại Xúc Sắc → Xúc Sắc Hoàng Kim → Vua trò chơi. Five stars per rank; points per star: 100,150,220,320,450,650,900,1300. Rating 1000 is the zero-star Bronze baseline. Original rating records are preserved.
- Rank gift at rank r (zero-based): 100*(r+1)² Gem and 2*(r+1)² Ruby, once. Rank 1+ additionally unlocks the supplied square frame. Highest achieved rank is retained so demotion does not remove gift eligibility. Frames remain owned after demotion. Server checks ownership when equipping.
- Avatars show the character's face with the selected square frame. Menu, Profile, Friends and Global share the avatar/progression presentation. Bronze uses a default border; the provided set contains seven higher-rank emblems/frames.
- The twenty supplied buff images are optimized WebP derivatives. Original files remain unchanged. At LMS entry, local gacha animation cycles cards then stops at the buff already selected by the server; sound follows the SFX setting. Other players' cards stay face-down until revealed. Tooltips/focus describe actual server conditions.

Validation: `node scripts/test-progression-pve.cjs` (SQL and combat), `node scripts/test-lms-buffs.cjs`, `node scripts/test-online-runtime.cjs`, TypeScript. Browser checks cover mode Start → rank overview without joining queue until Find Match, mobile Profile, PvE win → reward → next stage, gacha final card and focus tooltip. Browser API fixtures were used; live Supabase needs the migration before deployment can be exercised end-to-end.
